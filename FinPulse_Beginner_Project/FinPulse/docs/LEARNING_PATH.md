# FinPulse Learning Path

## Lesson 1 — What are we building?
A banking analytics system that turns raw customer/account/transaction/loan data into trusted KPIs and customer insights.

## Lesson 2 — Database basics
Learn table, row, column, primary key, foreign key, relationship.

## Lesson 3 — Data quality
Learn nulls, duplicates, invalid values, orphan foreign keys and date checks.

## Lesson 4 — SQL
Learn SELECT, WHERE, GROUP BY, JOIN, CTE, subquery, window functions.

## Lesson 5 — RFM
Recency = how recently a customer transacted.
Frequency = how often they transacted.
Monetary = how much they spent/transacted.

## Lesson 6 — Segmentation
Use RFM first; then K-Means after understanding the features.

## Lesson 7 — Churn prediction
Define a target, create features using historical data, split train/test, evaluate precision/recall/F1/ROC-AUC.

## Lesson 8 — Explainability
Use SHAP to understand which features influence model predictions.

## Lesson 9 — Power BI
Connect the trusted analytical data to visuals and KPIs.

## Lesson 10 — Portfolio
Add ERD, data dictionary, lineage, screenshots, architecture, SQL and README.
